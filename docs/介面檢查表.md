# 介面檢查表（繁中化）

第 6 階段裝好中文之後，進遊戲逐項檢查。每一項都要看有沒有下列問題：

| 症狀 | 代表什麼 |
|---|---|
| 方框（□） | 字型缺這個字，或 fontconfig 沒生效 |
| 問號（?） | ImGui 類 mod 沒設中文字型，或檔案編碼錯誤 |
| `$` 開頭的文字（例如 `$SKI_Settings`） | 介面翻譯檔缺這個鍵 |
| 英文 | 還沒翻譯 |
| 空白名稱 | 插件缺中文字串表 |
| 簡體字、對岸用語 | 轉繁漏掉 |
| 同一名詞不同譯法 | 來源不同，需要釘選 |

發現問題時：截圖，並在最下方的紀錄表寫下位置與症狀。

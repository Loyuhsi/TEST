# 第 6 階段：繁中化（不新增任何插件）

英文版的重建（第 5 階段）完成後，才疊上中文。原則：

- **不新增任何插件**：
  - 完整插件是 253／254，只剩 1 個名額；輕量插件是 4012／4096。
  - 翻譯一律用 DSD 的 JSON、字串表或介面檔等散檔。
  - 翻譯者提供的「同名替換插件」只在版本和我們的完全相同時才用，而且優先選 DSD 版。
- **每一層翻譯都是獨立的 mod**：
  - 全部放在 `ZH` 分隔線下，這一組排在三個 `Pages -` 修正 mod 之下、其他所有 mod 之上。
  - 目標清單（`data/target/modlist.txt`）已經寫好這些資料夾，`create --apply` 會建立空資料夾。
  - 遊戲有問題時，可以把 ZH 整組停用，和英文版比較。
- **只限個人使用**：蘇禾的漢化包、Nexus 的翻譯與轉換後的結果，都不得分享或上傳。

順序說明：使用者選擇「先漢化，再玩測試路線」。所以第 0 節先備份英文版，第 5 階段第 11 節的測試路線和介面檢查表，在本階段最後一起玩。

預估時間：自動化部分數小時；AI 批次翻譯最長 24 小時；遊戲內檢查與修正要數天。

## 2. 字型

### 2.1 遊戲介面字型（fontconfig）

1.5.97 只會讀 `Interface\fontconfig.txt`。工具會把官方中文字型設定，和目前生效的介面字型設定（Edge UI、Sanguis）合併，讓所有字型名稱都指向中文字型。

1. 關閉 MO2，先試跑：
   ```bat
   python tools\zh\fontconfig.py --pm D:\PM ^
     --official "D:\PM\mods\ZH - 官方繁中字串\interface\fontconfig_cn.txt" --out-mod "D:\PM\mods\ZH Overrides"
   ```
2. 看報告中「目前生效的 fontconfig.txt」來自哪個 mod（工具會略過 `ZH Overrides` 自己上一次的輸出），再加上 `--apply` 執行一次。
3. 開 MO2，對 `ZH Overrides` 按右鍵 →「Information」→「Conflicts」，確認 `interface\fontconfig.txt` 由它勝出。

### 2.2 ImGui 類 mod 的字型

這些 mod 自己畫介面，不讀 fontconfig，要各自設定：

- 要改的設定檔，依相同路徑**複製到 `ZH Overrides`** 再改。不要改原檔。
- 字型用支援繁體的 **Noto Sans TC**（Google Fonts，SIL OFL 授權，免費）。
- 如果 mod 讓你選字形範圍，選完整中文（Full），不要選只含簡體常用字的範圍。
- 中文字型很大，若造成卡頓，回報 Claude 討論改用精簡字型。

| Mod（我們的資料夾） | 設定方式（以該 mod 說明為準） |
|---|---|
| Wheeler（`Wheeler - Quick Action Wheel of Skyrim`） | `SKSE\Plugins\wheeler\resources\fonts\fontConfig.ini`：把 `font = English` 改成檔內註解列出的中文選項（Wheeler 內附中文字型） |
| SkyPrompt（`SkyPrompt`，2.3.20） | 已經高於需要的 2.3.13。字型放 `Interface\ImGuiIcons\Fonts`，翻譯檔在 `SKSE\Plugins\<mod>\translations\<mod>_<語言>.json` |
| Dialogue History（`Dialogue History`） | 字型放 `Interface\ImGuiIcons\Fonts`，設定在 `Interface\DialogueHistory\fonts.ini` |
| PhotoMode（`PhotoMode`，3.0.4） | ImGui 字型，依 mod 說明設定 |
| LamasTinyHUD | Nexus 頁面（mod 82545）有 Noto Sans SC 選用檔。簡體字型可能缺繁體字，出現問號時換成繁體字型（保持同檔名） |
| SKSE Menu Framework（`SKSE Menu Framework2`） | 依 mod 說明設定字型與字形範圍 |
| dMenu | 依 mod 說明；無法設定就維持英文 |
| Community Shaders（1.9.1） | 按 `End` 開選單，在設定裡找語言或字型；它的記錄顯示有中日韓字型候選。沒有中文就維持英文 |
| Prisma UI | 網頁式介面，通常直接用系統字型；出現方框再回報 |

Scaleform 類的介面（SkyUI、QuickLoot、moreHUD、TrueHUD、Compass Navigation 等）讀 fontconfig 和翻譯檔，不用另外設定。

### 4.4 DSD 包：安裝並轉成繁體

1. 在 MO2 按工具列的「Install a new mod from an archive」，選 Nolvus 的 DSD 壓縮檔，名稱填 `ZH - 蘇禾 Nolvus DSD`（已經有這個空資料夾，選 Merge）。M&V 的 DSD 包名稱填 `ZH - 蘇禾 MV DSD`。
   - 裝好後，mod 資料夾裡應該是 `SKSE\Plugins\DynamicStringDistributor\…`。如果 MO2 說內容結構不對，截圖回報。
2. 關閉 MO2，先試跑轉換：
   ```bat
   python tools\zh\opencc_convert.py "D:\PM\mods\ZH - 蘇禾 Nolvus DSD" "D:\PM\mods\ZH - 蘇禾 MV DSD" "D:\PM\mods\ZH - DBReV 中文" ^
     --pins D:\PM\zh-work\pins_chs_cht.tsv
   ```
3. 看報告的轉換數量，然後在同一行指令最後加上 `--in-place` 實際轉換。
   - 每個被改的檔案旁邊會留一份 `.bak`，遊戲不會讀它。
   - 重跑時 `.bak` 會保留第一次的原檔。
4. **原生繁中優先**：有 Nexus 繁中翻譯的插件，要把蘇禾 DSD 裡同一個插件的資料夾**搬到** `D:\PM\_replaced\zh-sohe-overridden\`（搬移，不要刪除），否則 DSD 可能蓋回去。
   - 資料夾位置：`ZH - 蘇禾 … \SKSE\Plugins\DynamicStringDistributor\<插件檔名>\`。
   - 對象：`Vigilant.esm`、`Unslaad.esm`、`BSHeartland.esm`、`3DNPC.esp`、`Wyrmstooth.esp`、`evgSIRENROOT.esm`，以及 AHO 的主插件。

### 4.5 MCM 英文備援

先做這一步，Other 包的比對（4.6）才找得到 BSA 裡的英文檔：


### 4.6 Other 包：先比對版本

Other 包會取代介面、MCM 和腳本檔。它們是為特定 mod 版本做的，版本不符會壞掉，所以要先比對：

1. 關閉 MO2，試跑比對：

2. 把 `reports\zh_diff_pack.csv` 和 `.txt` 改名為 `zh_diff_pack-nolvus.*`。

   ```bat
     --accept-to "D:\PM\mods\ZH - 蘇禾 Nolvus Other" --apply
   ```
   - 原檔只在 BSA 裡的（例如腳本）會判為 skip，不會複製，數量寫進回報。
4. M&V 的 Other 包照做一次（`--pack "D:\zh-packs\MV Other"`，輸出到 `ZH - 蘇禾 MV Other`，報告改名為 `-mv`）。

## 7. AI 翻譯剩下的文字

用 Claude API 把剩餘英文翻成台灣繁中，輸出成 DSD、介面檔和字串表（不新增插件）。

1. **金鑰**（使用者自己做，不要貼進對話或任何檔案）：
   - 到 Claude Console（`platform.claude.com`）的 API Keys 頁面建立金鑰（帳戶需先儲值）。
   - 設成 Windows 的**使用者環境變數** `ANTHROPIC_API_KEY`：開始 → 搜尋「環境變數」→「編輯您帳戶的環境變數」→ 新增。
   - 重新開啟 Claude Desktop，讓本地代理的命令列讀得到。
2. **粗估**（不會送出任何資料）：
   ```bat
   python tools\zh\llm_translate.py estimate --work D:\PM\zh-work --glossary D:\PM\zh-work\glossary_en_zh.tsv
   ```
3. **試翻 20 組**（會花錢，約幾美分；先問使用者）：
   ```bat
   python tools\zh\llm_translate.py run --work D:\PM\zh-work --glossary D:\PM\zh-work\glossary_en_zh.tsv --limit 20 --mode sync --yes
   ```
   - 用記事本開啟 `D:\PM\zh-work\llm_cache.jsonl`，看譯文品質。
   - 報告最後一行「剩下的估計」是**依這次實測**推估全部的費用（含思考 token）。
4. **把金額告訴使用者，得到同意後**全部翻譯（批次模式通常約 1 小時內完成，最長 24 小時）：
   ```bat
   python tools\zh\llm_translate.py run --work D:\PM\zh-work --glossary D:\PM\zh-work\glossary_en_zh.tsv --yes
   ```
   - 執行中不要關閉視窗。
   - 不小心中斷時，重跑同一行：工具會先回收已送出的批次（已付費，不會重送），再繼續。
5. **輸出成 mod**（先關閉 MO2）：
   ```bat
   python tools\zh\llm_translate.py apply --work D:\PM\zh-work --pm D:\PM --out-mod "D:\PM\mods\ZH - AI 翻譯"
   ```
   - 字串表一律以「遊戲目前讀到的中文表」為底，只補新譯；官方插件（本體、DLC、CC）的字串表永遠不寫。
6. 重跑第 6 節的 `coverage.py`，看剩下的條數。

說明：

- 沒有加 `--yes` 時，任何文字都不會送出。
- 預設模型是 `claude-opus-5`、effort `medium`，可用 `--model`、`--effort` 更換。
  - 換之前先用 `--limit 20` 比較品質。
  - 實測費用依「模型＋effort」分開記錄。
- 預設用批次 API（Message Batches），價格是一般的 50%。
- 被拒絕或格式檢查不通過的條目，會改用同步模式逐條重試；同步模式會啟用伺服器端的備援模型（fallbacks）。仍失敗的保留英文，列在 `llm_failed.jsonl`。
- 每次執行的實際用量記在 `D:\PM\zh-work\llm_usage.jsonl`。

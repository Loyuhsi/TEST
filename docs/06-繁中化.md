# 第 6 階段：繁中化（不新增任何插件）

在英文基準版（EN-baseline）穩定之後，才疊上中文。原則只有三條：

- **不新增任何插件**：插件名額只剩約 27 個。翻譯一律用 DSD 的 JSON、字串表或介面檔等散檔。
- **每一層翻譯都是獨立的 mod**，放在 MO2 清單的最下方，隨時可以停用排查。
- **只限個人使用**：蘇禾的漢化包與轉換後的結果都不得分享或上傳。

預估時間：自動化部分數小時；遊戲內檢查與修正要數天。

## 0. 準備

1. 確認 EN-baseline 備份已完成。
2. 安裝翻譯工具需要的套件：
   ```bat
   cd /d C:\PagesTools
   python -m pip install -r requirements-zh.txt
   ```
3. 建立資料夾 `D:\zh-packs`，用來解壓縮漢化包（不要放在 `D:\PM\mods` 裡）。
4. 在 MO2 左側清單**最下方**建立分隔線：右鍵 →「Create separator」，命名 `ZH`。之後所有 `ZH` 開頭的 mod 都放在它下面。

## 1. 切換遊戲語言

1. 關閉 MO2。
2. 用記事本開啟 `D:\PM\profiles\Pages-ZH\Skyrim.ini`。因為 Profile 設定了 LocalSettings，要改的是 Profile 裡的這一份。
3. 在 `[General]` 段落找到 `sLanguage`，改成：
   ```ini
   sLanguage=CHINESE
   ```
4. 確認 `[Archive]` 的 `sResourceArchiveList2` 裡仍有 `Skyrim - Voices_en0.bsa`。官方繁中只有文字、沒有配音，語音維持英文。

## 2. 啟用官方繁中字串

1. 開啟 MO2，找到 `ZH - 官方繁中字串`（第 2 階段建立的），勾選啟用。
2. 把它拖到 `ZH` 分隔線下方的第一個位置。

## 3. 字型

### 3.1 遊戲介面字型（fontconfig）

1.5.97 只會讀 `Interface\fontconfig.txt`。工具會把官方中文字型設定，和目前生效的介面字型設定（Edge UI、Sanguis）合併，讓所有字型名稱都指向中文字型。

1. 關閉 MO2，先試跑：
   ```bat
   python tools\zh\fontconfig.py --pm D:\PM ^
     --official "D:\PM\mods\ZH - 官方繁中字串\interface\fontconfig_cn.txt" --out-mod "D:\PM\mods\ZH Overrides"
   ```
2. 看報告中「目前生效的 fontconfig.txt」來自哪個 mod，再加上 `--apply` 執行一次。
3. 開啟 MO2 按 `F5`，啟用 `ZH Overrides`，把它拖到**整個清單的最下方**（最高優先）。
4. 對 `ZH Overrides` 按右鍵 →「Information」→「Conflicts」，確認 `interface\fontconfig.txt` 是由它勝出。
5. 用 SKSE 啟動遊戲到主選單，進遊戲看看物品欄：原版的名稱應該已經是繁體中文（mod 的文字這時多半還是英文）。出現方框就停下來回報。

### 3.2 ImGui 類 mod 的字型

這些 mod 自己畫介面，不讀 fontconfig，要各自設定。共通做法：

- 要改的設定檔，依相同路徑**複製到 `ZH Overrides`** 再改。不要改原檔。
- 字型建議用支援繁體的 **Noto Sans TC**（Google Fonts，SIL OFL 授權，免費）。
- 如果 mod 讓你選字形範圍，選完整中文（Full），不要選只含簡體常用字的範圍。
- 中文字型很大，若造成卡頓，回報 Claude 討論改用精簡字型。

| Mod | 設定方式（以該 mod 說明為準） |
|---|---|
| Wheeler | `SKSE\Plugins\wheeler\resources\fonts\fontConfig.ini`：把 `font = English` 改成檔內註解列出的中文選項（Wheeler 內附中文字型） |
| SkyPrompt | 版本需 **2.3.13 以上**（舊版載入中文字型會當機）。字型放 `Interface\ImGuiIcons\Fonts`，翻譯檔在 `SKSE\Plugins\<mod>\translations\<mod>_<語言>.json` |
| Dialogue History | 字型放 `Interface\ImGuiIcons\Fonts`，設定在 `Interface\DialogueHistory\fonts.ini` |
| PhotoMode | ImGui 字型，依 mod 說明設定 |
| LamasTinyHUD | Nexus 頁面（mod 82545）有 Noto Sans SC 選用檔。簡體字型可能缺繁體字，出現問號時換成繁體字型（保持同檔名） |
| SKSE Menu Framework | 讀遊戲的 SWF 字型，有字形範圍設定 |
| dMenu | 依 mod 說明；無法設定就維持英文 |

SkyPrompt 的版本可在 MO2 的「Version」欄查看。低於 2.3.13 時，從 Nexus 下載新版，安裝到同名資料夾 `SkyPrompt` 並選 Replace。

## 4. 基礎元件

1. **Dynamic String Distributor（DSD）1.4.3**（Nexus mod 107676）：安裝為新 mod `Dynamic String Distributor`。只有 SKSE 外掛，不佔插件名額。
2. **Scaleform Translation Plus Plus NG**（Nexus mod 77359）：更新到 **1.10**（Files 分頁的 MAIN 檔）。安裝到清單中原有的同名資料夾 `Scaleform Translation Plus Plus NG`，選 Replace。
3. 關閉 MO2，執行 `python tools\audit_skse.py --pm D:\PM`，確認沒有 `[失敗]`。

- 授權：禁止轉載，只限自己玩。
- 內容是簡體，部分由 AI 翻譯，所以要轉成台灣繁體。

### 5.2 絕對不要下載

- `[Misc] 共享缺失MCM及DSD` 裡轉載的 Nexus 檔案（例如 DSD、Settings Loaders），這些一律從 Nexus 下載。
- Redux 版、6.0.19 舊版、M&V 2.40.1 的包，以及上表以外的任何東西。

### 5.3 解壓縮與名詞釘選

1. 用 7-Zip 把兩個 Other 包和本體＋CC 包解壓到 `D:\zh-packs` 底下各自的資料夾：`D:\zh-packs\Nolvus Other`、`D:\zh-packs\MV Other`、`D:\zh-packs\本體CC`。兩個 DSD 包不用解壓，5.4 節直接從壓縮檔安裝。
2. 列出本體＋CC 包的內容並回傳（第一行讓檔案用 UTF-8 儲存，簡體檔名才不會變成問號）：
   ```bat
   chcp 65001
   dir /s /b "D:\zh-packs\本體CC" > reports\zh_pack_basegame_list.txt
   ```
   Claude 會告訴你保留哪些。原則：官方已有繁中的本體與 DLC 一律用官方的，只保留官方缺的部分（通常是部分 CC）。
3. 如果本體包裡有字串表（`.strings` 等），先產生「名詞釘選表」。轉繁時，它會把社群用語改成官方繁中名詞：
   ```bat
   python tools\zh\strings_glossary.py chs-cht --a "D:\zh-packs\本體CC" ^
     --b "D:\PM\mods\ZH - 官方繁中字串\strings" --out D:\PM\zh-work\pins_chs_cht.tsv
   ```

### 5.4 DSD 包：安裝並轉成繁體

1. 在 MO2 按工具列的「Install a new mod from an archive」，選 `Ultimate DSD v1.2` 的壓縮檔，名稱填 `ZH - 蘇禾 Nolvus DSD`。M&V 的 DSD 包名稱填 `ZH - 蘇禾 MV DSD`。
   - 裝好後，mod 資料夾裡應該是 `SKSE\Plugins\DynamicStringDistributor\…`。如果 MO2 說內容結構不對，截圖回報。
2. 關閉 MO2，先試跑轉換：
   ```bat
   python tools\zh\opencc_convert.py "D:\PM\mods\ZH - 蘇禾 Nolvus DSD" "D:\PM\mods\ZH - 蘇禾 MV DSD" ^
     --pins D:\PM\zh-work\pins_chs_cht.tsv
   ```
   沒有做 5.3 的釘選表就拿掉 `--pins ...` 那段。
3. 看報告的轉換數量，然後在同一行指令最後加上 `--in-place` 實際轉換。每個被改的檔案旁邊會留一份 `.bak` 備份，遊戲不會讀它。
4. 本體＋CC 包依 Claude 的指示整理後，把內容複製到 `D:\PM\mods\ZH - 蘇禾 本體CC`（資料夾裡直接就是 `SKSE`、`strings` 等），在 MO2 按 `F5` 並啟用，再用上面的指令轉換。

### 5.5 Other 包：先比對版本

Other 包會取代介面、MCM 和腳本檔。它們是為特定 mod 版本做的，版本不符會壞掉，所以要先比對。

1. 關閉 MO2，試跑比對：
   ```bat
   python tools\zh\diff_pack.py --pack "D:\zh-packs\Nolvus Other" --pm D:\PM
   ```
2. 把 `reports\zh_diff_pack.csv` 和 `.txt` 改名為 `zh_diff_pack-nolvus.*`，上傳給 Claude 確認。
3. 確認後，只複製通過比對（accept）的檔案：
   ```bat
   python tools\zh\diff_pack.py --pack "D:\zh-packs\Nolvus Other" --pm D:\PM ^
     --accept-to "D:\PM\mods\ZH - 蘇禾 Nolvus Other" --apply
   ```
4. M&V 的 Other 包照做一次（`--pack "D:\zh-packs\MV Other"`，輸出到 `ZH - 蘇禾 MV Other`，報告改名為 `-mv`）。
5. 用 5.4 的 `opencc_convert.py` 把這兩個資料夾也轉成繁體（先試跑，再加 `--in-place`）。

> **注意**：Other 包裡如果有 `.esp`、`.esm`、`.esl`，一律不要自己加進清單，先問 Claude。

安裝前後：

## 8. （選用）SSE Auto Translator

SSE Auto Translator（SSE-AT，Nexus mod 111491）可以掃描清單、自動下載 Nexus 上連結的翻譯，並轉成 DSD。

- 它**找不到標示為「Traditional Chinese」的翻譯**，所以第 7 節要手動裝。
- 它內建的機器翻譯（Google、DeepL）**輸出簡體**，不要用。缺的部分交給第 11 節。
- 目標語言選 Chinese，輸出 mod 命名 `ZH - SSE-AT`，再用 `opencc_convert.py` 轉繁。

## 9. MCM 與介面翻譯檔

所有漢化包都裝好、轉好之後，關閉 MO2：

```bat
python tools\zh\mcm_txt.py scan --pm D:\PM
python tools\zh\mcm_txt.py make-chinese --pm D:\PM --out-mod "D:\PM\mods\ZH Overrides"
python tools\zh\mcm_txt.py make-chinese --pm D:\PM --out-mod "D:\PM\mods\ZH Overrides" --apply
```

- 替缺中文版的介面檔建立 `_CHINESE.txt`，先填英文，避免畫面出現 `$KEY`。
- 把 BSA 裡的 `_ENGLISH.txt` 另存成散檔，讓 Scaleform Translation++ 有英文備援。
- 蘇禾的包有時把中文放在 `_english.txt`，這沒關係，工具會以勝出的內容為準。

## 11. AI 翻譯剩下的文字

用 Claude API 把剩餘英文翻成台灣繁中，輸出成 DSD、介面檔和字串表（不新增插件）。

1. 取得 API 金鑰：到 Claude Console（`platform.claude.com`）的 API Keys 頁面建立金鑰（帳戶需先儲值）。
2. 在**同一個**命令提示字元視窗設定金鑰（只存在這個視窗，不會寫進任何檔案）：
   ```bat
   set ANTHROPIC_API_KEY=貼上你的金鑰
   ```
3. **估價**（不會送出任何資料）：
   ```bat
   python tools\zh\llm_translate.py estimate --work D:\PM\zh-work
   ```
   把 `reports\zh_llm-estimate.txt` 上傳，確認費用可接受再繼續。
4. **試翻 5 組**：
   ```bat
   python tools\zh\llm_translate.py run --work D:\PM\zh-work --glossary D:\PM\zh-work\glossary_en_zh.tsv --limit 5 --yes
   ```
   - 用記事本開啟 `D:\PM\zh-work\llm_cache.jsonl` 看譯文品質。
   - 批次模式要等批次處理完。想立刻看到結果，可以在指令後面加 `--mode sync`（只有 5 組，費用很少）。
5. **全部翻譯**（批次模式通常約 1 小時內完成，最長 24 小時）：
   ```bat
   python tools\zh\llm_translate.py run --work D:\PM\zh-work --glossary D:\PM\zh-work\glossary_en_zh.tsv --yes
   ```
   執行中不要關閉視窗。若不小心中斷，先回報 Claude 再重跑（已完成的會保留在快取，不用重付）。
6. **輸出成 mod**（先關閉 MO2）：
   ```bat
   python tools\zh\llm_translate.py apply --work D:\PM\zh-work --pm D:\PM --out-mod "D:\PM\mods\ZH - AI 翻譯"
   ```

說明：

- 沒有加 `--yes` 時，任何文字都不會送出。
- 預設模型是 `claude-opus-5`，可用 `--model` 更換（例如較便宜的 `claude-sonnet-5`），換之前先用 `--limit 5` 比較品質。
- 預設用批次 API（Message Batches），價格是一般的 50%。
- 被拒絕或格式檢查不通過的條目，會改用同步模式逐條重試；同步模式會啟用伺服器端的備援模型（fallbacks）。仍失敗的保留英文，列在 `llm_failed.jsonl`。
- 報告會顯示實際用量換算的費用。

## 12. MO2 中文 mod 的順序

在 `ZH` 分隔線下方，由上到下（越下面越優先）：

```
ZH（分隔線）
ZH - 官方繁中字串          ← 最低
ZH - 蘇禾 本體CC
ZH - 蘇禾 Nolvus DSD
ZH - 蘇禾 MV DSD
ZH - 蘇禾 Nolvus Other
ZH - 蘇禾 MV Other
ZH - SSE-AT（選用）
ZH - Nexus 繁中 - …（每個翻譯一個）
ZH - AI 翻譯
ZH Overrides              ← 最高，整個清單的最後一個
```

`Dynamic String Distributor` 和 `Scaleform Translation Plus Plus NG` 不需要放在這裡。

## 13. 重新檢查與遊戲內驗證

1. 關閉 MO2，重跑 `coverage.py`、`check_plugins.py`、`audit_skse.py`。
2. 進遊戲，依 [介面檢查表](介面檢查表.md) 逐項檢查，並走一次 [測試路線](測試路線.md)。
3. 找不到某段文字從哪裡來時，開啟 DSD 的除錯資訊：
   - 把 DSD 的 `SKSE\Plugins\DynamicStringDistributor.ini` 複製到 `ZH Overrides` 的相同路徑。
   - 把 `EnableDebugInfo` 設為開啟（依檔內格式）。遊戲中就能看出哪些字串來自 DSD。
   - 查完記得關掉。

## 不要做的事

- **不要用大學漢化**：它要求遊戲語言設為英文，和本流程衝突。
- **不要加入任何翻譯用的新 ESP／ESM／ESL**：插件名額不夠。
- 不要分享、上傳或散佈任何漢化成果或轉換後的檔案。

## 常見問題

| 畫面症狀 | 可能原因 | 處理 |
|---|---|---|
| 方框（□） | 字型沒有這個字 | 確認 `ZH Overrides` 的 fontconfig 勝出（第 3.1 節） |
| 問號（?） | ImGui 類 mod 沒設中文字型 | 第 3.2 節 |

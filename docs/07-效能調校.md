# 第 7 階段：筆電效能調校

目標：在測試路線上維持 50–60 FPS 以上（補幀前的內部畫格），連續玩 2 小時穩定，溫度可接受。

原則是**先量測，再調整**，每次只改一項，改完走一次[測試路線](測試路線.md)比較。

## 1. 怎麼量測

### 1.1 SSE Display Tweaks 的畫面資訊（OSD）

它可以顯示 FPS、畫格時間，以及 **VRAM 使用量對比系統給的預算**。

1. 找到 `SSE Display Tweaks` 資料夾中的 `SKSE\Plugins\SSEDisplayTweaks.ini`，用記事本開啟（只看，不要改）。
2. 在 `D:\PM\mods\Pages - 設定覆寫\SKSE\Plugins\` 建立 `SSEDisplayTweaks_Custom.ini`。這個檔案裡的設定會蓋過原本的設定，而且更新 mod 也不會消失。
3. 在原檔中找到 OSD 相關段落，依檔內註解把「啟用 OSD」和「顯示 VRAM」的那幾行，連同段落標題（例如 `[OSD]`）一起寫進 `_Custom.ini` 並改成開啟。
4. 遊戲中畫面角落會出現資訊。

判讀：

- **VRAM 使用量要低於預算**，最好留 1–1.5 GB 餘裕（經驗值）。超過預算時，遊戲會卡頓，而不是單純掉 FPS。
- 畫格時間忽高忽低，就是卡頓。

### 1.2 Community Shaders 效能資訊

1. 遊戲中按 `End` 開啟 CS 選單。
2. 開啟 Performance Overlay，可以看到每個效果花多少時間。
3. 吃最多時間的效果，就是優先要關或調低的對象（通常是 SSGI）。

## 2. 筆電與 Windows 設定

| 項目 | 設定 |
|---|---|
| 電源 | 一律插電。Windows「設定 → 系統 → 電源與電池 → 電源模式」：插電時選「最佳效能」 |
| 廠商效能模式 | 在廠商控制軟體（例如 Armoury Crate、Alienware Command Center）開 Turbo／效能模式 |
| 獨顯直連（MUX） | 切到獨顯模式（名稱可能是 dGPU、Ultimate），需重新開機；或開 Advanced Optimus。外接螢幕接在獨顯的輸出埠也可以 |
| BatteryBoost、Whisper Mode | 在 NVIDIA App 中關閉 |
| 圖形喜好設定 | 「設定 → 系統 → 顯示器 → 圖形」→ 新增 `D:\PM\STOCK GAME\SkyrimSE.exe` → 選「高效能」 |
| Windows 縮放 | 100%。或對 `SkyrimSE.exe` 按右鍵 →「內容」→「相容性」→ 覆寫高 DPI 縮放 |
| 分頁檔 | C 槽 20480–40960 MB（第 1 階段已設定） |

**NVIDIA 控制面板**：「管理 3D 設定」→「程式設定」→ 加入 `D:\PM\STOCK GAME\SkyrimSE.exe` →「電源管理模式」選「偏好最高效能」。

## 3. 畫面設定

### 3.1 解析度與視窗模式

1. 關閉 MO2，用記事本開啟 `D:\PM\profiles\Pages-ZH\SkyrimPrefs.ini`。
2. `[Display]` 段落：
   - `iSize W`、`iSize H`：設成螢幕原生解析度（例如 2560 和 1600）。
   - `bFull Screen=0`、`bBorderless=1`（無邊框視窗）。
3. 不要用 SSE Display Tweaks 的「borderless upscale」，它和 Community Shaders 不相容；CS 也不支援獨占全螢幕。

### 3.2 CS Upscaling：DLSS 加 FSR 補幀

1. 遊戲中按 `End` 開啟 CS 選單，找到 Upscaling。
2. 升頻方式選 **DLSS**，品質選 **Quality** 或 **Balanced**（Tier S 可試 DLAA）。
3. 開啟 **Frame Generation**（FSR 補幀）。條件：
   - 無邊框或視窗模式。
   - 螢幕更新率 **120 Hz 以上**。拔掉電源時若螢幕降到 60 Hz，補幀會自動失效。
4. CS Upscaling 只提供 FSR 補幀，沒有 DLSS 補幀。

> **注意**：清單有 Skyrim Souls RE。它和 CS 的補幀一起使用時，選單會變透明。如果很在意，關閉補幀或停用 Skyrim Souls，回報 Claude 再決定。

### 3.3 用 Display Tweaks 限制 FPS

限制內部 FPS 可以讓畫面更穩，也能降溫。例如內部 60，補幀後約 120。

1. 在原本的 `SSEDisplayTweaks.ini` 找到 `FramerateLimit` 所在的段落標題（例如 `[Render]`）。
2. 在 `SSEDisplayTweaks_Custom.ini` 寫入同樣的段落標題，以及：
   ```ini
   FramerateLimit=60
   ```

### 3.4 （選用實驗）DLSS 5 神經渲染

**結論：主要設定不用 DLSS 5。** 照 3.2 節用 CS Upscaling（DLSS 4 升頻加 FSR 補幀）。DLSS 5 只當第 8 階段備份之後的選用實驗。

**DLSS 5 是什麼**
- 它不是升頻或補幀，而是用 AI 重新打光、補上皮膚、頭髮、材質的細節，讓畫面更寫實。它**不會讓遊戲變快，反而很吃效能**。
- 官方狀態（2026-09）：
  - 9 月 3 日隨 NBA 2K27 推出，只支援 RTX 50（含筆電），驅動 616.64 以上。
  - 每款遊戲都要由開發商整合，Skyrim 沒有官方支援。
- 效能：桌機 RTX 5080 在 NBA 2K27 開 DLSS 5 後，1440p 掉約 54–60%，4K 掉約 58–73%。RTX 5080 Laptop 約等於桌機 5070，本清單又重，預期內部 FPS 會掉一半左右。

**Skyrim 能用的非官方模組**（都是 2026-08 底才出現的測試版）

| 模組 | 說明 | 建議 |
|---|---|---|
| DynamicShaderFrameGen（Nexus 190154） | SKSE 外掛，支援 1.5.97。有 DLSS 升頻、FSR 3.1 補幀；實驗分支另有 DLSS 5 神經渲染和 DLSS 多倍補幀（RTX 50 原生支援 3×／4×）。 | 要試就用這個 |
| Open Shaders With DLSS5（190062） | 要把 Community Shaders 整個換成 Open Shaders 分支；不支援 HDR 與 DLSS 補幀。 | 不建議 |
| ReShade／RenoDX 的 DLSS5 套件 | 要在遊戲根目錄放代理 DLL。 | 不建議 |

**用 DynamicShaderFrameGen 的限制與風險**
- 必須關閉 CS 的 **Upscaling**（包含它的 FSR 補幀）和 **HDR**；也不能和其他升頻或補幀外掛並用。
- 神經渲染用的 `nvngx_dlssnr.dll` 不是 NVIDIA 公開 SDK 的檔案，外掛只接受 310.8.x。顯示卡驅動更新後可能失效。
- 有 Skyrim Souls RE 時，補幀可能讓選單變透明（和 3.2 節同樣的問題）。
- 在 4K 開 3× 以上的多倍補幀，轉動鏡頭時會拖影。
- 它的選單（按住 `Home`）有 **NR Render Scale**（0.25–1.0），調低可以降低神經渲染的成本。

**什麼時候、怎麼試**
1. 第 7 階段的基準設定完成、第 8 階段備份之後才試。
2. **開始前先回報 Claude**，取得當時的檔案版本與詳細步驟（這些模組更新很快）。
3. 在 MO2 複製設定檔，例如 `Pages-ZH-DLSS5`，只在這個設定檔啟用 DynamicShaderFrameGen，並關閉 CS 的 Upscaling 與 HDR。CS 的設定可能是兩個設定檔共用，切回 `Pages-ZH` 時確認 Upscaling 已重新開啟。
4. 走一遍測試路線，用外掛內建的 FPS 顯示比較 FPS、畫面和選單。外部的 FPS 工具只會顯示內部畫格數。
5. 不滿意就切回 `Pages-ZH`，不必移除任何東西。

## 4. 依顯示卡分級的建議

這是依 Nolvus 需求表、M&V 建議和清單內容推定的，實際以 OSD 量測為準。

| 項目 | Tier A：RTX 4090／5080 Laptop（16 GB） | Tier S：RTX 5090 Laptop（24 GB） |
|---|---|---|
| 解析度／升頻 | 1080p–1600p，DLSS Quality 或 Balanced，加 FSR 補幀 | 1440p／1600p，DLSS Quality 或 DLAA，加 FSR 補幀 |
| 材質 | 約 14 個 4K／8K 選項換成 2K；超出預算才用 VRAMr 輕度預設 | 保留；VRAMr 可不用 |
| 草 | FFF（iMinGrassSize=60）加 NGIO 快取 | 同左；可用 Grass Optimizations 並延伸草地距離 |
| DynDOLOD | High，超出預算時重建為 Medium | High |
| CS 效果 | 全開，SSGI 要實測 | 全開，含 SSGI |
| 物理（SMP） | FSMP 自動調整開、第一人稱 SMP 關 | 預設 |

補充：

- RTX 5090 Laptop 效能約等於桌機 4070 Ti Super／5070，優勢在 24 GB VRAM，不是運算速度。
- RTX 5080 Laptop 約等於桌機 5070，也和 RTX 4090 Laptop 相近。
- 同一個型號在不同筆電的功耗可差很多（例如 80–150 W）。低功耗的機種可能要往下降一級。

## 5. VRAM 超出預算時（依序嘗試）

1. **Texture Downscaler**（清單中已有，來自 M&V）：
   - 它在載入時跳過最大的材質層級，不修改任何檔案。
   - 設定檔是 `SKSE\Plugins\TextureDownscaler.ini`：每種材質（Diffuse、Normal、Parallax 等）各有上限，設為 0 表示不縮小。
   - 複製到 `Pages - 設定覆寫` 再調整。Tier S 若 VRAM 充足，可以考慮全部設 0；Tier A 保持較輕的設定。
   - 裝有 SKSE Menu Framework 時，也能在遊戲中即時調整。
2. **把 4K／8K 選項換成 2K**。下表是依資料夾名稱推定的候選：

   | 資料夾 |
   |---|
   | Granite Mountains [4K] |
   | Sons of Skyrim - Textures [4K] |
   | Draugrs - PBR 4K |
   | Boreal Whiterun - Complex Parallax - 8k 4k 2k 1k |
   | Ash Yam 2K-8K by iimlenny |
   | Whiterun City Stone Walls - Parallax [4K] |
   | Rocky Mossy Complex Parallax for Northern Roads [4K] |
   | Tomato's Bridge Texture Parallax 2k 4k |
   | Paraglider Replacers 2k-4k |
   | Gryphonknight Regalia - PBR 4k |
   | Shattered Royal Armor PBR 4k |
   | Obi's Cimmerian 3BA BHUNP SMP 4K |
   | Obi's Zamorian Thief 3BA UBE BHUNP 4K SMP |
   | Obi's Desert Sorceress outfit 4K 3BA UBE BHUNP SMP |
   | Lore-Friendly Load Screen Compendium (21-9) (4K) |

   - 做法：到該 mod 的 Nexus 頁面下載 2K 版，安裝到**同一個資料夾名稱**並選 Replace。自己記下換了哪些。
   - 載入畫面合集是 21:9 版，順便換成 16:9 版。
3. **VRAMr**（Nexus mod 90557）：前兩步仍超出預算才用，選輕度預設。
   - 它會產生一個很大的輸出 mod，要跑好幾個小時。
   - 之後換了材質就要重跑。先和 Claude 討論再做。

## 6. 物理模擬（FSMP）

在遊戲的 MCM 中找到 FSMP（Faster HDT-SMP）的設定選單，Simplification 頁面：

- 關閉第一人稱物理。
- 戴假髮時關閉 SMP 頭髮。
- 開啟「依畫格時間自動調整同時啟用的 SMP 骨架數」。

找不到這個選單時，回報 Claude。

## 7. 溫度

- 長時間遊玩時，用廠商控制軟體或你習慣的監控工具觀察 CPU／GPU 溫度與時脈。
- 如果時脈持續掉下來（過熱降頻），先降低 FPS 上限，再考慮關閉 SSGI 等效果。

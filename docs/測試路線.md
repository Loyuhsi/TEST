# 固定測試路線

每次重要改動後（EN-baseline、繁中化、效能調校）都走同一條路線，結果才能互相比較。全程約 30–60 分鐘。

## 準備

1. 從 MO2 用 SKSE 啟動遊戲。第一次要等左上角的「Compiling Shaders」跑完，再開始量測。
2. 開啟 SSE Display Tweaks 的畫面資訊（OSD），要能看到 FPS 和 VRAM（設定方式見[第 7 階段](07-效能調校.md)）。
3. 開**新遊戲**：在 RaceMenu 建立角色，選任一種開局，直到可以自由移動。
4. 立刻存檔，命名 `TEST-START`。之後每次測試都從這個存檔開始。
5. 開啟主控台（按 `~`，數字 1 左邊的鍵），輸入下面兩行，每行按 Enter：
   ```
   tgm
   tmm 1
   ```
   - `tgm`：無敵模式，避免測試途中死亡。
   - `tmm 1`：顯示所有地圖標記，方便快速旅行。
6. 再按一次 `~` 關閉主控台。

## 傳送方式

下表的 `coc` 指令是社群常用的地點 ID（UESP 這次無法直接查證）。輸入後若畫面顯示找不到地點，改用**地圖快速旅行**：開地圖，點選同名地點，選擇快速旅行。

## 路線

每個地點都做同樣的事：

1. 站定 30 秒，讓畫面載入完成。
2. 慢慢把鏡頭轉一圈（360°）。
3. 截一張含 OSD 的圖。
4. 依說明走 2–5 分鐘，注意卡頓與畫面問題。

| # | 地點 | 怎麼去 | 做什麼 | 主要考驗 |
|---|---|---|---|---|
| 1 | 河木鎮與森林 | 主控台 `coc Riverwood` | 在村內走一圈，再往村外森林走 3 分鐘 | 樹木、植被、光影 |
| 2 | 雪漫城外平原（FFF 花海） | 從河木鎮沿大路往北走向雪漫城（約 5–8 分鐘） | 途中離開道路，走進草地與花叢 | 草地密度、草地快取、遠景 LOD |
| 3 | 雪漫城外圍 | 繼續走到雪漫城大門與馬廄一帶 | 在城外繞一圈，看城牆與遠景 | 大型建築、LOD 銜接 |
| 4 | 雪漫城內 | 從大門進城 | 走到龍霄宮前的階梯 | 城市區塊載入、NPC 數量 |
| 5 | 獨孤城 | 主控台 `coc SolitudeOrigin`，或地圖快速旅行到獨孤城 | 沿主街走到藍宮前 | 城市、PBR 材質、VRAM 高峰 |
| 6 | 馬卡斯 | 主控台 `coc MarkarthOrigin`，或地圖快速旅行到馬卡斯 | 在城內走一圈 | 石造建築、室外光影 |

想直接回到雪漫城城內時，可以用 `coc WhiterunOrigin`（同樣無效時改用快速旅行）。

## 要注意什麼

| 項目 | 怎麼看 | 記錄方式 |
|---|---|---|
| FPS | OSD | 大約的平均值與最低值 |
| VRAM | OSD 的使用量與預算 | 兩個數字，例如 `13.2 / 15.1 GB` |
| 卡頓 | 畫格時間突然跳高、畫面頓一下 | 有／無，發生在哪裡 |
| 缺材質 | **紫色**的物件 | 位置與截圖 |
| 缺模型 | **紅色驚嘆號** | 位置與截圖 |
| LOD 問題 | 遠景閃爍、物件突然出現、漂浮的草或石頭 | 位置與截圖 |
| 草長在物件裡 | 草穿過地板或石頭 | 位置與截圖 |
| 跳出遊戲（CTD） | 遊戲直接關閉 | 時間、位置、最新的 `crash-*.log` |
| 中文（第 6 階段之後） | 見[介面檢查表](介面檢查表.md) | 截圖 |

## 回傳

- 填好的紀錄表（可以直接貼在對話中）。
- 每個地點的 OSD 截圖。
- 有問題的畫面截圖。
- 跳出遊戲時：`%USERPROFILE%\Documents\My Games\Skyrim Special Edition\SKSE\` 裡最新的 `crash-*.log`（上傳前先遮掉使用者名稱，見[回報格式](回報格式.md)）。

> **注意**：`TEST-START` 存檔用過主控台指令，只拿來測試，不要用它正式遊玩。

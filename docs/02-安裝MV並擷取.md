# 第 2 階段：安裝 M&V 並擷取需要的部分

這一階段用 Wabbajack 安裝 Mages & Vikings（M&V）2.6.2，把目標清單需要的資料夾以硬連結放進 `D:\PM`，再取出官方繁中字串。確認無誤後，刪除 M&V 以騰出空間。

- 預估時間：半天到一天（下載約 230 GB，視網速而定）。
- 前提：第 1 階段的退出條件都已達成，Claude 已看過 `preflight` 報告。

## 關於硬連結（先讀這段）

NTFS 允許一個檔案有好幾個「名字」，這叫硬連結。`D:\MV\mods\X\a.dds` 和 `D:\PM\mods\X\a.dds` 可以指向**同一份資料**：

- 只佔一份空間。檔案總管會把兩邊都算成完整大小，但 D 槽剩餘空間不會減少。
- 刪掉其中一個名字，資料還在，另一個名字照常可用。所以擷取完可以放心刪除 `D:\MV`。
- 兩個名字必須在**同一個分割區**。
- 直接修改其中一個，另一個也會跟著變。所以之後要改設定檔時，一律先複製到別的 mod 再改（手冊會提醒）。

## 1. 用 Wabbajack 安裝 M&V 2.6.2

1. 開啟 Wabbajack。它會自動更新；版本需為 **4.2.3 以上**。
2. 確認設定頁顯示已登入 Nexus。
3. 進入模組清單庫（Browse Modlists／Gallery），在搜尋框輸入 `Mages`。
4. 找到 **Mages & Vikings**，確認版本是 **2.6.2**，按下載／安裝。Wabbajack 會先下載約 5.4 GB 的 `.wabbajack` 檔。
5. 在安裝設定畫面填入：
   - 安裝位置（Installation Location）：`D:\MV`
   - 下載位置（Download Location）：`D:\WJ-Downloads`
     - 如果另一顆硬碟有 250 GB 以上的空間，可以放那裡（例如 `E:\WJ-Downloads`），D 槽會比較寬裕。
6. 按「Install」開始安裝。
7. 等到 Wabbajack 顯示安裝完成。完成後 `D:\MV` 裡會有 `ModOrganizer.exe`、`mods`、`profiles`、`Stock Game` 等資料夾。

> **注意**
> - M&V 的說明提到**第一次安裝有時會失敗**。這時用相同的兩個資料夾再按一次 Install，已下載的檔案會保留。
> - 安裝中途不要讓 Steam 更新 Skyrim，也不要從 Steam 啟動遊戲。

## 2. （選做）第一次啟動 M&V

這一步不是必要的。M&V 跑的是 1.6.1170，和我們最後用的 1.5.97 不同，所以能不能進遊戲不影響後續。

1. 執行 `D:\MV\ModOrganizer.exe`。
2. 如果跳出 PageFile Manager 要調整分頁檔，選不要（第 1 階段已在 C 槽設定好）。
3. 右上方執行檔下拉選單選「SKSE」→「Run」，進到主選單後離開遊戲，再關閉 MO2。

## 3. 盤點 M&V（唯讀）

開啟命令提示字元（一般權限即可）：

```bat
cd /d C:\PagesTools
python tools\inventory.py --source mv --instance D:\MV
```

- 會掃描約 3700 個 mod 資料夾並計算大小，需要一些時間。
- 產生 `reports\inventory-mv.txt`、`.json` 和 `inventory-mv.csv`。
- 報告中「遊戲執行檔版本」應是 1.6.1170 系列，這是正常的。

## 4. 擷取需要的資料夾（harvest）

依 `data\analysis\provenance.csv` 中標為 `harvest_mv` 的約 650 個資料夾，以硬連結放進 `D:\PM\mods`。`--mo2-and-tools` 會一併連結 MO2 2.5.2 程式本體與 `tools\`（DynDOLOD、xLODGen、PGPatcher、SSEEdit、BethINI）。

1. **先試跑**（不會寫入任何檔案）：
   ```bat
   python tools\harvest.py --from mv --instance D:\MV --pm D:\PM --mo2-and-tools
   ```
2. 看畫面上的結果：
   - 「模式」是試跑。
   - 沒有「來源與 D:\PM 不在同一個磁碟分割區」的 `[失敗]`。
   - 「計畫中要從 mv 擷取的資料夾」會列出數量與「來源缺少」的數量。
3. 沒問題就**實際執行**：
   ```bat
   python tools\harvest.py --from mv --instance D:\MV --pm D:\PM --mo2-and-tools --apply
   ```
4. 完成後確認：
   - `D:\PM\ModOrganizer.exe` 存在。
   - `D:\PM\tools` 裡有 DynDOLOD、xLODGen 等工具。
   - `D:\PM\mods` 裡有許多資料夾。
5. 報告：`reports\harvest-mv.txt`、`.json` 和 `harvest-mv.csv`（每個資料夾一行）。

### 為什麼有些資料夾「來源缺少」

- 目標清單的 M&V 內容來自 2.5.x 時期；M&V 2.6 移除了其中 9 個 mod（Parrying RPG、One Click Power Attack NG、True Flasks NG、Simple Hunting Overhaul、Madmen、STB Widgets、STB Active Effects、Relationship Dialogue Overhaul、New Creature Animation - Werewolf）。
- 這 9 個大多也在 Nolvus 裡，已規劃在第 3 階段從 Nolvus 擷取；True Flasks NG 會在第 4 階段從 Nexus 下載。
- `harvest-mv.csv` 裡狀態為 `missing_in_source` 的資料夾，表示 M&V 2.6.2 沒有同名資料夾。它們會在第 4 階段改從 Nexus 下載，現在不用處理。

## 5. 取出官方繁中字串與字型

M&V 重建的 `Skyrim - Interface.bsa` 內含官方繁中字串與 `fonts_cn.swf`。**刪除 `D:\MV` 之前一定要先做這一步。**

1. 安裝解壓縮需要的套件：
   ```bat
   python -m pip install lz4
   ```
2. **先試跑**：
   ```bat
   python tools\zh\extract_official.py --game-dir "D:\MV\Stock Game" ^
     --extra-bsa "D:\MV\mods\Creation Club\_ResourcePack.bsa" ^
     --out-mod "D:\PM\mods\ZH - 官方繁中字串" --work D:\PM\zh-work --fallback-english
   ```
3. 確認「中文字串表」是 `[通過]`，再**實際執行**（同一行指令加上 `--apply`）：
   ```bat
   python tools\zh\extract_official.py --game-dir "D:\MV\Stock Game" ^
     --extra-bsa "D:\MV\mods\Creation Club\_ResourcePack.bsa" ^
     --out-mod "D:\PM\mods\ZH - 官方繁中字串" --work D:\PM\zh-work --fallback-english --apply
   ```
4. 結果：
   - `D:\PM\mods\ZH - 官方繁中字串`：中文字串表、`fonts_cn.swf`、`fontconfig_cn.txt` 等（第 6 階段才啟用）。
   - `D:\PM\zh-work\official_english`：英文字串表，第 6 階段做名詞對照表用。
   - 報告 `reports\zh_extract_official.txt`、`.json`。「字形判斷」應為 traditional。
   - 有英文但沒有中文字串表的插件，會先以英文暫代（`--fallback-english`），避免之後畫面出現空白名稱。

## 6. （選做）M&V 2.40.1 對照表

M&V 2.40.1 是最後一個 1.5.97 版本。它的清單可以告訴我們各 mod 的 1.5.97 版檔案 ID，第 4 階段替換 DLL 時會更省事。

1. 到 Nexus 的 M&V 頁面（mod 136238）→「Files」分頁，在最下方的封存檔（Archived files）中找到 **2.40.1**（file 703199）。直接網址：`https://www.nexusmods.com/skyrimspecialedition/mods/136238?tab=files&file_id=703199`
2. 手動下載這個 `.wabbajack` 檔（約數 GB），例如存到 `D:\WJ-Downloads`。
3. 產生對照表（只讀取檔案內的清單，不會安裝任何東西）：
   ```bat
   cd /d C:\PagesTools
   python tools\analysis\mv_wabbajack_map.py --wabbajack "D:\WJ-Downloads\Mages & Vikings.wabbajack" --out-dir data\analysis --out-prefix mv2401
   ```
   檔名以你實際下載的為準。
4. 產生 `data\analysis\mv2401_folder_map.csv` 和 `mv2401_modlist_meta.json`。第 4 階段執行 `audit_skse.py` 時會用到。
5. 完成後可以刪除這個 `.wabbajack` 檔。

## 7. 上傳報告，等 Claude 確認

把「要回傳的檔案」上傳，等 Claude 回覆可以刪除後再進行下一步。刪除無法復原，重新下載要再花好幾個小時。

## 8. 刪除 M&V 與下載檔

條件：`harvest-mv` 報告沒有 `[失敗]`，`zh_extract_official` 的中文字串表是 `[通過]`，而且 Claude 已確認。

1. 關閉 MO2 和 Wabbajack。
2. 在命令提示字元執行（請再三確認路徑）：
   ```bat
   rmdir /s /q D:\MV
   rmdir /s /q D:\WJ-Downloads
   ```
   也可以在檔案總管選取資料夾後按 `Shift + Delete`（不經過資源回收筒）。檔案很多，可能要跑一陣子。
3. `D:\PM\mods` 裡以硬連結擷取的檔案不受影響。
4. （選做）Wabbajack 自己的資料夾裡還存著 M&V 的 `.wabbajack` 檔（約 5.4 GB，在 C 槽），確認不再需要後可以刪除。

## 常見問題

**harvest 報「來源與 D:\PM 不在同一個磁碟分割區」？**
`D:\MV` 和 `D:\PM` 必須在同一個分割區。不要加 `--allow-copy`（會複製整份資料，佔用大量空間），先回報 Claude。

**畫面中文變成亂碼？**
工具會自動切換成 UTF-8 輸出。若仍有亂碼，報告檔（`.txt`）的內容是正確的，直接上傳報告即可。

**`extract_official` 顯示「此 BSA 使用 LZ4 壓縮」？**
沒有裝 `lz4`。執行 `python -m pip install lz4` 後再跑一次。

**刪除後 D 槽剩餘空間比預期少？**
先清空資源回收筒，再看一次。如果仍低於 500 GB，回報 Claude。

# 第 1 階段：準備筆電

這一階段只做準備，不安裝任何清單。做完後執行 `preflight.py`，把報告回傳給 Claude。

- 預估時間：2–4 小時（大部分是下載與等待）。
- 需要系統管理員權限。

## 開始前：D 槽空間怎麼用

M&V、Nolvus 和新的 `D:\PM` 三個資料夾都要放在 **D 槽同一個 NTFS 分割區**。這樣才能用「硬連結」共用檔案，不必複製兩份（硬連結的說明見第 2 階段）。

| 時間點 | D 槽上有什麼 | 約佔用 | 說明 |
|---|---|---|---|
| 第 2 階段安裝 M&V（最高峰） | `D:\MV` 386 GB + `D:\WJ-Downloads` 230 GB | 約 620 GB，另需 40–60 GB 餘裕 | Wabbajack 要求額外的 40–60 GB |
| 第 2 階段結束 | `D:\PM`（目標需要的約 650 個 M&V 資料夾） | 未實測，預估 100–200 GB | 刪除 `D:\MV` 和下載檔後，空間大多回來 |
| 第 3 階段安裝 Nolvus | 上一列 + `D:\Nolvus` Ultimate 426 GB | 預估 530–650 GB | **關閉封存（archiving）**，省下 193 GB |
| 第 4–5 階段 | 再加補下載的 mod 與重建的輸出 | 預估 600–830 GB | 新 mod 約 50–150 GB、輸出約 15–30 GB（都是估計） |
| 第 8 階段刪除 `D:\Nolvus` 後 | 只剩 `D:\PM` | 預估 450–600 GB | |

為什麼先裝 M&V、再裝 Nolvus：

- M&V 連同下載檔需要約 616 GB，是最佔空間的一步，要趁 D 槽還空的時候做。
- 裝完只留下目標需要的資料夾（以硬連結放進 `D:\PM`），其餘整個刪掉，再裝 Nolvus。
- 硬連結只能在**同一個分割區**內建立，所以三個資料夾都必須在 D 槽。

> **注意**
> - Steam 版 Skyrim 本身約 21 GB。如果你的 Steam 遊戲庫也在 D 槽，也要算進去。
> - C 槽要留至少 60 GB：分頁檔最多 40 GB，Wabbajack 的 `.wabbajack` 檔約 5.4 GB。

## 1. Windows 更新與執行環境

1. 開啟「設定 → Windows Update」，安裝所有更新並重新開機。
2. 安裝 **Visual C++ 2015–2022 可轉散發套件（x64）**。
   - 從 Microsoft 官網下載 `vc_redist.x64.exe`。
   - 如果安裝程式顯示「修復」，就按「修復」（M&V 的說明要求這樣做）。
3. 安裝 **.NET 6 Desktop Runtime** 和 **.NET 8 Desktop Runtime**。
   - 到 `dotnet.microsoft.com` 的 .NET 6.0 與 .NET 8.0 下載頁。
   - 各選「Desktop Runtime」的 **Windows x64** 安裝程式。兩個都要裝。
4. 安裝 **Python 3.12**（python.org 的 Windows 64-bit 安裝程式）。
   - 第一個畫面**一定要勾選「Add python.exe to PATH」**，再按「Install Now」。
   - 裝好後開「命令提示字元」，輸入 `python --version`，應顯示 `Python 3.12.x`。

## 2. 分頁檔（虛擬記憶體）

1. 按 `Win + R`，輸入 `sysdm.cpl`，按確定。
2. 切到「進階」分頁 → 效能區的「設定」→「進階」分頁 → 虛擬記憶體的「變更」。
3. 取消勾選「自動管理所有磁碟的分頁檔大小」。
4. 選 **C:**，點「自訂大小」：
   - 初始大小：`20480`
   - 最大值：`40960`
5. 按「設定」→「確定」，然後重新開機。

> 實測可行的替代做法：C 槽保持「系統管理的大小」，另在 D 槽（NVMe）設固定 `40960`／`40960`。兩個磁碟的分頁檔加起來即可，`preflight` 會判定通過。C 槽空間吃緊時用這個做法。

## 3. 建立資料夾與 Windows Defender 排除

1. 開啟「命令提示字元」，建立資料夾：
   ```bat
   mkdir D:\MV D:\Nolvus D:\PM D:\WJ-Downloads
   ```
   如果 M&V 的下載檔要放在另一顆硬碟（需約 250 GB），改建那一顆的資料夾，例如 `E:\WJ-Downloads`。
2. 開啟「Windows 安全性」→「病毒與威脅防護」→「病毒與威脅防護設定」下的「管理設定」。
3. 捲到最下面「排除項目」→「新增或移除排除項目」→「新增排除項目」→「資料夾」。
4. 依序加入 `D:\MV`、`D:\Nolvus`、`D:\PM` 和下載資料夾（例如 `D:\WJ-Downloads`）。

也可以用「以系統管理員身分執行」的命令提示字元一次加入：

```bat
powershell -Command "Add-MpPreference -ExclusionPath 'D:\MV','D:\Nolvus','D:\PM','D:\WJ-Downloads'"
```

## 4. Steam 版 Skyrim

必須是 **Steam 版** Skyrim Special Edition 加上 **Anniversary Upgrade**（或直接買 Anniversary Edition）。GOG 版不適用。

1. 在 Steam 遊戲庫中，對「The Elder Scrolls V: Skyrim Special Edition」按右鍵 →「內容…」。
2. 「一般」：取消勾選「在遊戲中啟用 Steam 內嵌介面」（Steam Overlay）。
3. 「更新」：自動更新選「**僅在我啟動此遊戲時更新**」。
4. 「語言」：選 **English**。
   - 整個安裝期間（第 1～3 階段）都保持英文。
   - Nolvus 要求 Dashboard 語言和 Steam 語言相同，而 Dashboard 沒有中文；M&V 則要求英文。
   - 中文會在第 6 階段用設定檔切換，不必動 Steam。
   - 只需要改**遊戲**的語言；Steam 介面語言維持繁體中文沒關係。改成 English 通常只會下載不到 1 KB，因為各語言字串本來就在 `Skyrim - Interface.bsa` 裡。
   - `文件\My Games\Skyrim Special Edition\Skyrim.ini` 裡若是 `sLanguage=CHINESE`（以前玩過中文留下的）不必改：Wabbajack 與 Nolvus 的 MO2 都用各自設定檔裡的 ini，不會讀這個檔。
5. 讓 Steam 下載完更新。目前版本應為 **1.7.104**（Nolvus Dashboard 3.8.11 以上與 M&V 2.6.2 都以此為準）。
6. 從 Steam 啟動遊戲一次，在啟動器按「Play」，進到主選單。
7. 主選單選 **CREATIONS**，先登入 Bethesda.net 帳號，再到 **OPTIONS** 選「**Download all owned Creation Club Creations**」下載**全部**內容，等全部顯示已安裝。
   - AE 升級在 Steam 上只是授權，沒有可下載的內容；CC 一定要在遊戲內下載。
   - 完整的 AE 內容共 **74 個 CC 插件**（約 5.85 GB），`preflight` 會檢查數量。
8. 下載完就離開遊戲。

> **注意**：這之後，在第 3 階段完成前**不要再從 Steam 啟動 Skyrim**。Bethesda 若推出新版本，啟動時會被更新，Wabbajack 與 Nolvus 的檔案檢查就會失敗。

## 5. 其他系統檢查

1. **MO2 全域實例**：按 `Win + R`，輸入 `%LOCALAPPDATA%` 開啟資料夾。
   - 如果裡面有 `ModOrganizer` 資料夾，把它改名成 `ModOrganizer.bak`。
   - 否則 Nolvus Dashboard 會報錯「Global ModOrganizer instance has been detected」。
2. **Killer 網路軟體**（Dell／Alienware 筆電常見）：
   - 開啟 Killer 的控制中心，關閉「Prioritization Engine」（必要時也關閉 Auto Bandwidth）。
   - 它會讓 Wabbajack 下載失敗。

## 6. 帳號

| 帳號 | 用途 | 要做的事 |
|---|---|---|
| Nexus Mods（Premium） | Wabbajack、Nolvus、MO2 下載 | 在 Wabbajack 的設定頁登入 Nexus |
| nolvus.net | Nolvus Dashboard 登入 | 到 nolvus.net 註冊。**不要**用 Nexus 的密碼 |
| mega.nz（免費） | Nolvus 部分檔案放在 mega | 註冊免費帳號，第 3 階段會用到 |
| 夸克網盤 | 第 6 階段下載蘇禾的漢化包 | 註冊帳號；可能要安裝夸克 PC 版才能下載 |

## 7. 取得工具包

工具包放在短路徑 `C:\PagesTools`。任選一種方式：

- **下載 ZIP**：在 GitHub 的 `loyuhsi/TEST` 頁面切換到分支 `claude/sharp-faraday-b8ax3h`，按「Code → Download ZIP」。解壓縮後，把資料夾改名並移到 `C:\PagesTools`，確認 `C:\PagesTools\tools\preflight.py` 存在。
- **用 git**：
  ```bat
  git clone -b claude/sharp-faraday-b8ax3h https://github.com/loyuhsi/TEST.git C:\PagesTools
  ```

> **注意**：Claude 之後可能會更新工具包。更新時重新下載即可，但**保留** `C:\PagesTools\reports` 資料夾（裡面是你的報告）。

## 8. 執行環境檢查（preflight）

1. 在開始選單搜尋「命令提示字元」，按右鍵 →「以系統管理員身分執行」（這樣才能檢查 Defender 排除項目）。
2. 執行：
   ```bat
   cd /d C:\PagesTools
   python tools\preflight.py --install-drive D:
   ```
3. 畫面會列出每一項的結果：`[通過]`、`[注意]`、`[失敗]`、`[資訊]`。
4. 報告存在 `C:\PagesTools\reports\preflight-日期時間.txt` 和 `.json`。

工具不會修改系統，只做檢查。

## 常見問題

**輸入 `python` 卻開啟 Microsoft Store？**
到「設定 → 應用程式 → 進階應用程式設定 → 應用程式執行別名」，關閉 `python.exe` 和 `python3.exe`，再重開命令提示字元。

**Skyrim 版本顯示 [注意]，不是 1.7.104.0？**
先讓 Steam 更新完再執行一次。如果 Steam 已推出比 1.7.104 更新的版本，先停下來回報 Claude（Nolvus 與 M&V 可能還不支援）。

**CC 插件少於 74 個？**
回到遊戲主選單的 CREATIONS，確認每一項都已下載完成。

**Steam 遊戲語言顯示 [失敗]？**
照第 4 節改成 English，等 Steam 下載完語言檔再執行一次。

**Python 用的是 3.13（例如 miniconda）可以嗎？**
可以。工具需要 3.12 以上；第 6 階段的套件（opencc、lz4、sse-plugin-interface、anthropic）都有 Windows 的 3.13 版本。

**Windows Defender 排除顯示 [資訊]「一般權限看不到排除清單」？**
Windows 只讓系統管理員讀取排除清單。以系統管理員身分開啟命令提示字元再執行 `preflight` 就能檢查；或到「Windows 安全性 → 病毒與威脅防護 → 設定 → 排除項目」自己確認。

**分頁檔顯示 [注意]？**
確認已經重新開機。設定要重開機才會生效。

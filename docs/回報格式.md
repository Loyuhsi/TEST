# 回報格式

每個階段結束（或卡住）時，把工具產生的報告上傳到對話，Claude 會判讀並告訴你下一步。

## 基本規則

1. 報告都在 `C:\PagesTools\reports\`。每個工具會產生：
   - `.txt`：給人看的結果。
   - `.json`：給 Claude 讀的完整資料。
   - 有些工具另外產生 `.csv`（每個資料夾或插件一行）。
2. **`.txt` 和 `.json` 一定要一起傳**，有 `.csv` 也一起傳。
3. 同一個工具跑過很多次時，只傳**最後一次**（`--apply` 之後）的結果。
4. 檔案很多時，可以把整個 `reports` 資料夾壓成一個 ZIP 上傳（不含 API 金鑰就沒問題）。
5. 上傳時附一句話說明：做到哪一步、有沒有遇到錯誤。

報告中的狀態：

| 標記 | 意思 |
|---|---|
| `[通過]` | 沒問題 |
| `[注意]` | 可能有問題，交給 Claude 判讀 |
| `[失敗]` | 必須先處理，不要進到下一步 |
| `[資訊]` | 只是資訊 |

## 各階段要上傳的檔案

| 階段 | 報告（`reports\`） | 其他 |

| 1 準備筆電 | `preflight-日期時間.txt`、`.json` | 筆電型號、螢幕解析度與更新率、有沒有 MUX |
| 2 M&V | `inventory-mv.*`（含 `.csv`）、`harvest-mv.*`（含 `.csv`）、`zh_extract_official.*` | 選做：`data\analysis\mv2401_modlist_meta.json`、`mv2401_folder_map.csv`；刪除後 D 槽剩餘空間 |
| 3 Nolvus | `inventory-nolvus.*`（含 `.csv`）、`harvest-nolvus.*`（含 `.csv`） | Nolvus Profile 的 `modlist.txt`、`plugins.txt`、`loadorder.txt`；Dashboard 確認畫面截圖；`skse64.log` |
| 4 組合 | `manifest.*`（含 `.csv`）、`build_instance-create.*`、`build_instance-verify.*`、`build_instance-sync-order.*`、`prune_dependents.*`、`prune-plan.csv`、`check_plugins.*`（含 `.csv`）、`audit_skse.*`（含 `.csv`）；用過才傳 `nexus_fetch.*` | `skse64.log`、`BackportedESLSupport.log`；當機時 `crash-*.log` |
| 5 輸出 | `build_instance-sync-order.*`、`check_plugins.*`、`audit_skse.*` | 測試路線紀錄與截圖；出錯時 DynDOLOD `Logs` 記錄檔、`NGIO-NG.log`、`crash-*.log` |
| 6 繁中化 | `zh_fontconfig.*`、`zh_pack_basegame_list.txt`、`zh_diff_pack-nolvus.*`、`zh_diff_pack-mv.*`、`zh_opencc.*`、`zh_mcm-scan.*`、`zh_mcm-make-chinese.*`、`zh_mcm.csv`、`zh_coverage.*`（含 `.csv`）、`zh_llm-estimate.*`、`zh_llm-run.*`、`zh_llm-apply.*`、`check_plugins.*`、`audit_skse.*` | 介面檢查表的結果與問題截圖 |

`.*` 表示 `.txt` 和 `.json` 兩個檔案。

## 記錄檔在哪裡

| 檔案 | 位置 |
|---|---|
| `skse64.log`、`BackportedESLSupport.log`、`crash-日期時間.log`、`NGIO-NG.log` | `%USERPROFILE%\Documents\My Games\Skyrim Special Edition\SKSE\`（「文件」被 OneDrive 同步時，在 `OneDrive\文件` 底下） |
| DynDOLOD、TexGen 記錄 | `D:\PM\tools\DynDOLOD\Logs\` |

在檔案總管的網址列貼上 `%USERPROFILE%\Documents\My Games\Skyrim Special Edition\SKSE` 按 Enter 就能直接開啟。

## 隱私

- **絕對不要貼上 API 金鑰**（`NEXUS_API_KEY`、`ANTHROPIC_API_KEY`），也不要貼任何密碼（Nexus、nolvus.net、mega、夸克）。
- 不要貼蘇禾漢化包的分享連結或提取碼。
- 工具產生的報告已自動把 Windows 使用者名稱遮成 `%USERPROFILE%`，可以直接上傳。
- **遊戲記錄檔不會自動遮蔽**（`skse64.log`、`crash-*.log` 等），裡面的路徑可能有你的使用者名稱。上傳前：
  1. 用記事本開啟。
  2. 按 `Ctrl + H`，「尋找目標」填你的 Windows 使用者名稱，「取代為」填 `USER`，按「全部取代」。
  3. 另存新檔後再上傳。
- 截圖前，確認畫面上沒有電子郵件、帳號名稱或金鑰。

## 截圖

- 按 `Win + Shift + S` 可以截取部分畫面，截好後直接在對話中貼上。
- 遊戲中截圖：Steam 截圖鍵在這個清單中不適用（不是從 Steam 啟動）。請用 `Win + Shift + S`，或無邊框模式下的 `Print Screen`。
- 截圖檔名建議寫上地點或畫面，例如 `雪漫城-OSD.png`、`MCM-SkyUI-方框.png`。

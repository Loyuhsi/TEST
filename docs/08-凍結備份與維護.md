# 第 8 階段：凍結、備份與維護

這份清單是「組出來的」，無法用任何安裝程式一鍵重裝。所以完成後要**凍結**（不再更新來源）、**備份**，並實際**測試還原一次**。

## 1. 凍結原則

- **永遠不要**在 Nolvus Dashboard 按 Update，也不要對任何清單執行 Wabbajack 更新。它們會改寫 Profile、刪除或重建 mod 資料夾。
- 只從 `D:\PM\ModOrganizer.exe` 用 SKSE 啟動遊戲，**不要從 Steam 啟動**。
- Steam 更新 Skyrim 不會影響 `D:\PM\STOCK GAME`，因為那是獨立的一份副本。Steam 的更新設定維持「僅在啟動時更新」即可。
- 不要修改 `D:\PM\STOCK GAME` 裡的檔案，也不要用 LOOT 自動排序。
- 想更新或新增 mod，照第 5 節的流程。

## 2. 要備份什麼

| 項目 | 路徑 | 為什麼 |
|---|---|---|
| Profile | `D:\PM\profiles\Pages-ZH` | 清單順序、插件順序、遊戲 ini、**存檔**（LocalSaves 讓存檔放在這裡） |
| MO2 設定 | `D:\PM\ModOrganizer.ini` | 遊戲路徑與執行檔清單 |
| 中文層 | `D:\PM\mods\` 底下所有 `ZH` 開頭的資料夾 | 轉換與比對花了很多時間 |
| 設定覆寫 | `D:\PM\mods\Pages - 設定覆寫` | 你的 ini 調整 |
| 8 個輸出 | `Pandora Output`、`BodySlide (Nude)`、`SYNTHESSIS`、`pgpatcher_output`、`grass CS`、`lodgen2`、`texgenCS`、`dyndolodCS2` | 重建要好幾個小時 |
| 翻譯工作資料 | `D:\PM\zh-work` | 含 AI 翻譯快取 `llm_cache.jsonl`，重做時不必再付費 |
| 決定與報告 | `C:\PagesTools\data\decisions.csv`、`C:\PagesTools\reports` | 每個資料夾的處理紀錄 |

備份放在 **D 槽以外**（另一顆硬碟、外接硬碟或雲端硬碟）。

## 3. 用 7-Zip 備份

先到 7-zip.org 安裝 7-Zip，並關閉 MO2。

### 方法一：滑鼠操作

1. 在檔案總管選取上表的資料夾與檔案（可以按住 `Ctrl` 多選）。
2. 按右鍵 →「7-Zip」→「加入壓縮檔…」。
3. 壓縮格式選 `7z`，檔名例如 `Pages-ZH-2026-10-01.7z`，存到備份位置。

### 方法二：命令列

以備份到 `E:\PagesBackup` 為例（請換成你的位置）：

```bat
"C:\Program Files\7-Zip\7z.exe" a "E:\PagesBackup\Pages-ZH-2026-10-01.7z" ^
  "D:\PM\profiles\Pages-ZH" "D:\PM\ModOrganizer.ini" "D:\PM\zh-work" ^
  "D:\PM\mods\ZH*" "D:\PM\mods\Pages - 設定覆寫" ^
  "D:\PM\mods\Pandora Output" "D:\PM\mods\BodySlide (Nude)" "D:\PM\mods\SYNTHESSIS" ^
  "D:\PM\mods\pgpatcher_output" "D:\PM\mods\grass CS" "D:\PM\mods\lodgen2" ^
  "D:\PM\mods\texgenCS" "D:\PM\mods\dyndolodCS2" ^
  "C:\PagesTools\data\decisions.csv" "C:\PagesTools\reports"
```

檔名中的日期請改成當天日期。每次大改動前都備份一次。

### （建議）完整備份整個 D:\PM

上面只備份「自己產生的東西」。來自 Nolvus 和 M&V 的 mod，刪除來源之後就只剩 `D:\PM` 這一份，而且那些版本以後不一定下載得到。如果有空間夠大的外接硬碟（約等於 `D:\PM` 的大小），建議再做一份完整副本：

```bat
robocopy D:\PM E:\PM-full /MIR /R:1 /W:1
```

- 硬連結的檔案在另一顆硬碟上會變成一般檔案，這是正常的。
- `/MIR` 會讓目的地和來源完全一致（目的地多的檔案會被刪掉），目的地請用專用資料夾。

## 4. 測試還原一次

1. 關閉 MO2。
2. 把 `D:\PM\profiles\Pages-ZH` 改名為 `Pages-ZH.old`。
3. 用 7-Zip 解壓縮備份檔，把 `Pages-ZH` 放回 `D:\PM\profiles\`。
4. 開啟 MO2，用 SKSE 啟動，讀取最近的存檔，玩幾分鐘。
5. 一切正常：刪除 `Pages-ZH.old`。有問題：刪掉解壓的那份，把 `Pages-ZH.old` 改回原名，並回報 Claude。

## 5. 刪除 D:\Nolvus

條件：

- 第 5–7 階段都已通過。
- EN-baseline 和中文版都已備份，還原測試也成功。
- Claude 已確認。

步驟：

1. 關閉所有程式。第 3 階段做的 Nolvus Profile ZIP 要保留。
2. 執行：
   ```bat
   rmdir /s /q D:\Nolvus
   ```
3. `D:\PM` 以硬連結取得的檔案（包括 `STOCK GAME`）不受影響。
4. 開啟 MO2，用 SKSE 啟動確認一切正常。

## 6. 之後想加 mod 的安全流程

1. **先備份**（第 3 節）。
2. **確認相容**：
   - 有 SKSE 外掛（DLL）的 mod，要有 1.5.97（SE）版或 NG 版。
   - 會新增插件的 mod，要注意名額：完整插件最多 254 個，目前只剩少量空位。
3. 在 MO2 安裝成新的 mod，放在適當位置並啟用。
4. 關閉 MO2，執行：
   ```bat
   cd /d C:\PagesTools
   python tools\check_plugins.py --pm D:\PM
   python tools\audit_skse.py --pm D:\PM
   ```
5. 依 mod 的類型，可能要重建輸出：

   | 新 mod 改動了什麼 | 要重跑 |
   |---|---|
   | 動畫、行為 | Pandora |
   | 服裝、體型 | BodySlide |
   | 地形、草、物件擺放 | NGIO 草地快取、xLODGen、TexGen、DynDOLOD |
   | 模型或 PBR 材質 | PGPatcher（之後再跑 TexGen、DynDOLOD） |
   | 物品、NPC、等級清單 | Synthesis |

6. 中文：
   ```bat
   python tools\zh\coverage.py --pm D:\PM --work D:\PM\zh-work
   python tools\zh\llm_translate.py estimate --work D:\PM\zh-work
   ```
   新增的文字不多時，照第 6 階段第 11 節翻譯並 `apply`（已翻過的在快取中，不會重付）。有 MCM 的話，再跑一次 `mcm_txt.py make-chinese`。
7. 新增插件或移除插件，對進行中的存檔都有風險。最安全的做法是開新遊戲。
8. 有問題就把報告上傳給 Claude。

## 7. 下載檔的管理

- `D:\PM\downloads` 存著第 4 階段下載的原始壓縮檔，會佔用不少 D 槽空間。
- 空間夠就保留，將來重裝某個 mod 比較快。
- 空間不夠時，移到其他硬碟存放，或在 MO2 的 Downloads 分頁刪除已安裝的檔案。

## 8. （選用）私人 .wabbajack

Wabbajack 可以把一個 MO2 實例「編譯」成 `.wabbajack` 檔，方便日後自己重裝。

- 它需要所有 mod 的原始下載檔。本流程為了省空間已刪掉一部分，要做之前先和 Claude 討論。
- **只能自己使用，絕對不能分享**：清單包含 Patreon 付費內容、Nolvus 的非 Nexus 檔案，以及只限個人使用的蘇禾漢化包。

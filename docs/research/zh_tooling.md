# zh_tooling

## SUMMARY
I re-checked the zh_tooling result against primary sources: Nexus GraphQL modFiles and descriptions, GitHub raw source for SSE-AT, STPP-NG, OpenCC, xTranslator and ImGui, moddingforge docs, nolvus.net, Steam appdetails, DeepL docs and the Wabbajack docs, plus the local modlist files. Most version and date claims hold: SSE-AT v3.2.5 (2026-09-19), DSD 1.4.3 (2026-05-19; runs on 1.5.97 and 1.6.640/1130/1170, 1.7 not listed), xTranslator 1.7.2 on Starfield page 313 (2026-08-31), STPP-NG 1.9 (2026-08-14, UTF-16 fix) and 1.10 (2026-08-24, adds 1.7.99), FontConfig Extended 1.1.0, BOBW 1.7.104.3, EET 4.35, Nolvus 6.0.20, 和光 v1.61, and Steam listing Traditional Chinese as text-only.

Corrections that change the plan:
- **SSE-AT misses Traditional translations.** Its Nexus scraper treats only 'Simplified Chinese' and 'Mandarin' as Chinese, so translations tagged 'Traditional Chinese' are never found.
- **Nexus's 'Simplified Chinese' tag also holds Traditional work.** 大學漢化 and 168 mods named 'Traditional Chinese' carry it. The 'Traditional Chinese' tag appears on only 8 mods, all created 2022-10 or later. SSE-AT output will therefore be mixed Simplified and Traditional.
- **SSE-AT's machine translation outputs Simplified.** It calls Google with 'zh-cn' and DeepL with 'zh'. For Traditional, use xTranslator with DeepL ZH-HANT or an LLM, or run OpenCC afterwards.
- **STPP-NG is one DLL for all game versions.** The risk is running an old STPP version on a newer runtime, not picking the wrong DLL variant. It reads extra-language and English-fallback files only from loose Data/Interface/Translations.
- **Runtime attribution looks inverted.** The Nolvus v6 snapshot contains BEES, which is only for 1.5.97–1.6.659, so Nolvus appears to run on 1.5.97. The MV snapshot has '1.6.1170 Missing Files' and no BEES, so MV may run on 1.6.1170. The target's 1.5-specific DLLs appear in neither snapshot, and 1.5.97 remains the most likely target runtime.
- **Minor:** the xTranslator Skyrim page's latest file is 1.4.4-alpha (its version label says 1.4.5). xTranslator also supports the OpenAI API. The OpenCC --ambiguities option needs the native CLI. The SSE-AT batch CLI does not run the online scan or downloads. DAV for Skyrim 1.5 is on line 4034, not 4027.

Missing facts added:
- 大學漢化 requires the game language set to English, which conflicts with the sLanguage=CHINESE pipeline.
- SkyPrompt needs version 2.3.13 or later for Chinese fonts and uses its own JSON translation files.
- Nolvus requires the Dashboard language to match Steam, and MV requires Steam set to English.
- On 1.5.97 the game reportedly reads only fontconfig.txt, so a CJK fontconfig must be supplied explicitly.
- Nolvus v6 Ultra needs at least 10 GB VRAM at 1080p, 406 GB of disk and 32 GB RAM.

- [high] SSE Auto Translator is a standalone Windows app for MO2 and Vortex. It scans the modlist, searches Nexus (and CDT for French), downloads translations, converts them to DSD and builds an Output Mod that goes at the bottom of the modlist. It includes Google Translator (free) and the DeepL API. It supports only plugins (.esp/.esm/.esl) and interface/*_<language>.txt; Papyrus support is 'planned'. Translations that are not linked from the original mod page can only be found through a masterlist. (https://moddingforge.com/docs/sse-at ; https://raw.githubusercontent.com/Cutleast/SSE-Auto-Translator/master/README.md)
- [high] SSE-AT supports Chinese as a target language and ships a vanilla database for Chinese, French, German, Italian, Japanese, Polish, Russian and Spanish, but not for Korean, Portuguese or Turkish. (https://moddingforge.com/docs/sse-at/faqs ; https://raw.githubusercontent.com/Cutleast/SSE-Auto-Translator/master/src/core/utilities/game_language.py)

(https://raw.githubusercontent.com/Cutleast/SSE-Auto-Translator/master/src/core/translation_provider/nm_api/nm_api.py (LANG_OVERRIDES; __scrape_mod_translations))
- [high] SSE-AT's built-in machine translation outputs Simplified Chinese. ## RISKS
- CORRECTION: SSE-AT cannot find Traditional-tagged translations. Its scraper maps only 'Simplified Chinese' and 'Mandarin' to Chinese, so translations tagged 'Traditional Chinese' on Nexus are never found (nm_api.py LANG_OVERRIDES). The original result left this as an open question; Traditional translations must be imported by hand.
- CORRECTION: The Nexus tag counts (7,863 Simplified vs 8 Traditional) are accurate, but the Simplified tag also covers Traditional work: 大學漢化 and 168 of the 522 mods named 'Traditional Chinese' carry it. SSE-AT downloads will be a mix of Simplified and Traditional with different noun sets, and the ratio is not evidence that nearly all translations are Simplified.
- CORRECTION (new): SSE-AT's built-in Google ('zh-cn') and DeepL ('zh') translation produces Simplified Chinese. For Traditional output, use xTranslator with DeepL ZH-HANT or an LLM, or run OpenCC after SSE-AT's machine translation.
- CORRECTION: STPP-NG is a single universal DLL. The risk is an old STPP version on a newer game runtime, not a 'DLL variant mismatched to the runtime'. The 1.9 changelog says 'languages requiring UTF-16', not specifically CJK. 1.10 adds 1.7.99; support for Steam's current 1.7.104 is unverified.
- CORRECTION: STPP-NG's English fallback reads only loose Data/Interface/Translations/*_ENGLISH.txt. An _ENGLISH file packed in a BSA gives no fallback, so the key shows as a raw $KEY when the _CHINESE file lacks it.
- CORRECTION: The runtime attribution is inverted or unsupported. The Nolvus v6 snapshot contains BEES (1.5.97–1.6.659 only), pointing to a 1.5.97 Nolvus stock game. The MV 2.6.2 snapshot contains '1.6.1170 Missing Files' and no BEES, pointing to 1.6.1170, not 1.5.97. 'Nolvus v6 is an AE list' is true only for its content, not its executable. The target still looks like 1.5.97 because of its 1.5-specific DLL mods, which are in neither snapshot.
- CORRECTION: The xTranslator Skyrim page (134) has a version label of 1.4.5, but its newest file is 1.4.4-alpha (2023-09-14). xTranslator's API list should also include OpenAI (since 1.5.3).
- CORRECTION: The SSE-AT batch CLI supports only a basic modlist scan, importing local archives and building the output. Online scan and downloads cannot be scripted, so the pipeline is not fully headless.
- CORRECTION: The OpenCC --ambiguities mode needs the native CLI; the pip or Python CLI does not support it.
- CORRECTION: Local line reference: 'Dynamic Armor Variants for Skyrim 1.5' is on line 4034, not 4027.
- CORRECTION: SKSE Menu Framework features cannot be tied to version numbers (3.17 SWF fonts, 3.18 English fallback), because the 3.16–3.18 files all carry the date 2026-09-17 and empty changelogs. Confidence is lowered accordingly.
- CORRECTION: The Menu Maid 2 rename INI syntax was not verified. Only the rename feature itself is confirmed.
- 大學漢化 fills the English slot and requires game language English. Using it conflicts with sLanguage=CHINESE: _CHINESE.txt MCM files would not load, and the SSE-AT vanilla database would not apply. It also predates AE/CC content after 1.6.342.
- Mixed scripts and nouns remain the core quality risk: official Traditional nouns, 大學, ANK, 重光 and 和光. Without OpenCC plus a pinned noun dictionary, the game shows inconsistent names.
- Fonts: on a 1.5.97 stock game, the EXE reportedly reads only fontconfig.txt, so the official Chinese font mapping probably does not apply automatically. Sanguis (Latin only) and Edge UI (Futura) fontconfigs give boxes until a CJK fontconfig wins. Higher-priority mods ('Nolvus HUD Settings (Edge UI)', 'CustomFixes1', 'overwrite2') may also ship Interface files; check MO2 conflicts.
- ImGui mods show '?' or crash without CJK fonts: Wheeler, Dialogue History, PhotoMode, LamasTinyHUD, SMF, dMenu and SkyPrompt. SkyPrompt below 2.3.13 reportedly crashes when loading Chinese fonts. Large CJK glyph sets can cause stutter or CTDs on a laptop, so use subset fonts.
- DSD index-based entries (INFO NAM1, QUST CNAM/NNAM, PERK EPFD) can misalign after mod updates. DSD loses to SkyPatcher names and Description Framework BOOK CNAM. DSD does not list 1.7.x, which matters if the user stays on Steam 1.7.104 without BOBW.
- SSE-AT covers only plugins and interface txt. Papyrus .pex, MCM Helper config.json, DF, SkyPatcher, Menu Maid, QJO and CSF JSON, SkyPrompt JSON, SWF-hardcoded labels and textures (the FWMF paper maps) stay English unless handled by hand.
- Translating .pex literals that act as identifiers (event names, StorageUtil/JContainers keys, paths) breaks scripts. This is inferred; xTranslator only locks internal variables.
- No Nexus Chinese translation exists for Nolvus- or MV-specific patches, merges and outputs. They must be machine-translated, and the Bilibili Nolvus packs are unverified in version, license and format.
- SSE-AT scrapes about 4,000 mod pages and calls the Nexus API (20k requests/day, then 500/hour). Keep download threads at the default of 1.
- A Wabbajack update deletes added mods (the SSE-AT output, fonts, overrides) unless they are prefixed [NoDelete], and it loses INI edits. The Nolvus Dashboard language must match Steam, and MV requires Steam set to English. A Taiwan user whose Steam is set to 繁體中文 must switch Steam to English before installing.
- Licensing: 和光 forbids integration and redistribution of its nouns, so converted or merged output is for personal use only.
- Hardware: Nolvus v6 Ultra needs at least 10 GB VRAM at 1080p and about 406 GB of disk plus 188 GB of downloads. A typical 8 GB-VRAM gaming laptop is below the published minimum, and a combined Nolvus + MV install doubles disk needs.
- Still unverified: whether an English 1.7.104 install contains *_chinese strings for all masters, CC plugins and the 1.7 free content. Missing ones give English or blank names for those items.

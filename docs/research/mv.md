# mv

## SUMMARY
I re-checked the load-bearing claims against the MV GitHub repo, the Nexus GraphQL API, the SKSE site, the Wabbajack changelog, wiki and validation reports, and my own range-read of the published MV .wabbajack. Most of the original result holds. Nine claims needed correcting (see the CORRECTION entries in risks).

**Confirmed:**
- Mages & Vikings (MV) is at 2.6.2: gallery entry dated 2026-09-05, Nexus MAIN file 800961.
- Download, installed and total sizes: 230 GB, 386 GB and 616 GB. All 3772 archives pass validation.
- Hardware per the README: RTX 4070 or better, 32 GB RAM, no VRAM figure.
- Since v2.5 the runtime is 1.6.1170. All 178 game-file archives require Steam AE 1.7.104.0 (148 of them are Creation Club files). Wabbajack patches SkyrimSE.exe, the launcher, Skyrim.esm, Update.esm and Voices_en0.bsa inside the Stock Game folder.
- SKSE is 2.2.8 (Nexus file 792256, built for 1.6.1170, now marked OLD_VERSION). MO2 is 2.5.2 and Root Builder is used.
- MV is ENB-only: seven presets, Kauz on by default. It contains no Community Shaders files.
- The folder-to-Nexus mapping counts are right: 3694 folders, 2965 single-archive, 631 multi-archive, 93 inline-only.
- The target-overlap counts are right: 561 MV-only, 323 in both, 2444 Nolvus-only, 716 in neither. The Load Order Library snapshots are line-reversed compared with MO2's modlist.txt.

**Key corrections:**
1. The Stock Game is not "English-only" for text. The rebuilt Skyrim - Interface.bsa already contains the official Chinese strings for Skyrim, Update and the three DLCs, plus fonts_cn.swf and fontconfig_cn.txt. The Creation Club resource pack also has Chinese strings. Steam lists Traditional Chinese (text only) for Skyrim SE, so vanilla Traditional Chinese text is already on disk after install. What still needs translating is mod content.
2. The switch from Nemesis to Pandora happened in v2.4, not v2.5.
3. The SKSE "only the latest Steam version" quote is about Skyrim classic (LE), not SE/AE.
4. The Nexus collection's revision 4 has 3588 mods, not 3537. It was published before the 2.6.2 upload, so it probably reflects 2.6.1.
5. The "about 38% faster desktop 4070" figure could not be verified and has been removed.

**Added:**
- 36 mods already ship `_chinese.txt` MCM files. There are 85 English MCM files across 77 mods.
- Norden UI and Font Overhaul supply fontconfig.txt, so a CJK font mod must win that conflict.
- MV contains 316 SKSE DLLs, 3625 plugin files and 16,202 scripts.
- Nolvus v6 is also ENB-based and points to 1.5.97. The target list has Crash Logger - 1.5.97 and BEES, so the target's Community Shaders stack comes from neither base list.

## RISKS
- CORRECTION: The claim that 'the Stock Game BSAs and Voices are rebuilt/patched from English sources, so Chinese strings and fonts must be layered as mods' is partly wrong. The rebuilt Skyrim - Interface.bsa already includes the official 'chinese' strings for Skyrim, Update and the 3 DLCs, plus fonts_cn.swf, fontconfig_cn.txt and translate_chinese.txt. CC _ResourcePack.bsa includes chinese strings too. Only the voices are English, and Traditional Chinese has no official audio anyway. What still needs translating is the mod content.
- CORRECTION: The Nemesis-to-Pandora switch is listed under MV v2.4, not v2.5. v2.5 only says animations broken 'due to the switch to Pandora' were fixed.
- CORRECTION: The SKSE-site quote 'supports the latest version of Skyrim available on Steam, and only this version' refers to Skyrim classic (LE, 'currently 1.9.32'), not SE/AE. For AE the site lists build 2.3.1 for 1.7.104, and also keeps SE 2.0.20 for 1.5.97 and GOG 2.2.6 for 1.6.1179.
- CORRECTION: The Nexus pseudo-collection agq2zq revision 4 has modCount 3588 (not 3537 mod files). It was updated 2026-09-05T13:23Z, before the 2.6.2 upload, so it likely reflects 2.6.1 rather than 2.6.2.
- CORRECTION: 'No archive name matches ... True PBR' is imprecise. MV includes many 'Complex Material and PBR' Nexus mods, but only their CM files; there are zero textures\pbr files and no Community Shaders DLLs or shaders. Several ENB Light mods carry 'Community Shader Light Limit Fix Light' in their Nexus names.
- CORRECTION: Stock Game CreateBSA detail. There are 16 BSAs in Stock Game (15 'Skyrim - *.bsa' plus MarketplaceTextures.bsa) and 1 in mods\Creation Club (_ResourcePack.bsa), 17 in total. Skyrim - Animations.bsa is copied unchanged, and binkw64.dll is produced by patching 1.7.104's bink2w64.dll.
- CORRECTION: The 'desktop RTX 4070 about 38% faster than the laptop 4070' figure could not be verified and has been removed. The confirmed difference is 8 GB/128-bit GDDR6 for the laptop vs 12 GB/192-bit GDDR6X for the desktop. The MV README says only 'RTX 4070 or higher', without desktop or laptop.
- CORRECTION: The Nexus MAIN file 800961 (5,413,325,283 B) and the gallery CDN .wabbajack (5,416,496,998 B) differ in size, so they are not the same bytes. Prefer the gallery build, which is the one validated and described in modlists.json.
- CORRECTION: The Wabbajack wiki adds a restriction the original omitted: the install folder cannot be the same as another list's ('lists can't be merged'). MV and Nolvus must go in separate folders; only the downloads folder may be shared.
- Game version lock: Wabbajack needs the Steam install at exactly 1.7.104.0 (178 hash-matched game files, 148 of them CC, including Curios). A new Bethesda patch before or during install breaks it until the author recompiles. Set Steam to update only on launch.
- Runtime mismatch: MV runs 1.6.1170 (SKSE 2.2.8 and 316 runtime-specific SKSE DLLs). The target list shows 1.5.97 (BEES, Crash Logger - 1.5.97, Nolvus base). Every MV DLL mod carried into the target must be replaced with its 1.5.97 build, or dropped if none exists. SKSE 2.2.8 is also already OLD_VERSION on Nexus.
- Laptop hardware: MV defaults are 2560x1440, 2048 shadows, uGridsToLoad 5, full ENB (Kauz) and DynDOLOD Full, tuned for 'RTX 4070 or higher' and 32 GB RAM. An 8 GB laptop GPU will need Performance LODs, the Texture Downscaler, lower INIs and possibly the lighter visual stack.
